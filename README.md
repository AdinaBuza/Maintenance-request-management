 Maintenance Request Management System

 Project Overview

The Maintenance Request Management System is a web application designed to help users submit, manage, and track maintenance requests.

The application aims to simplify the process of reporting maintenance problems and monitoring their resolution.

 Main Objectives

- Allow users to create an account and log in.
- Allow users to submit maintenance requests.
- Allow users to view and track their requests.
- Allow technicians to view and manage submitted requests.
- Provide a clear overview of each request's status and priority.

Planned Technologies

- Frontend: React with TypeScript
- Backend: C# and ASP.NET Core Web API
- Database: MySQL
- Data Access: Entity Framework Core
- Version Control: Git and GitHub

Main Features

The initial version of the application will include:

- User authentication.
- Maintenance request creation.
- Maintenance request listing and details.
- Request priority management.
- Request status management.

 Project Status

The project is currently in the initial planning and documentation stage. The application will be developed incrementally, starting with its basic structure and core functionality.
