 Project Overview

1. Introduction

The Maintenance Request Management System is a web application designed to facilitate the submission, management, and monitoring of maintenance requests.

The application will provide a centralized platform where users can report maintenance problems and track the progress of their requests.

 2. Problem Description

In many organizations, maintenance problems are reported through informal methods, such as emails, phone calls, or direct communication.

These methods can make it difficult to keep track of requests, prioritize problems, assign tasks, and monitor their resolution.

The proposed application aims to improve this process by providing a structured and accessible system for managing maintenance requests.

 3. Project Purpose

The main purpose of this project is to develop a web application that simplifies the maintenance request management process.

Users will be able to submit requests, while technicians will be able to view, manage, and update their status.

 4. Intended Users

The application will support the following user roles:

- User: Can create maintenance requests and monitor their status.
- Technician: Can view assigned requests and update their status.
- Administrator: Can manage users and oversee the application.

 5. Main Objectives

The main objectives of the project are:

- To provide user authentication.
- To allow users to submit maintenance requests.
- To organize requests by category and priority.
- To allow technicians to manage requests.
- To track the status of each request.
- To maintain a clear overview of the request resolution process.

 6. Expected Outcome

The expected outcome is a functional web application that provides an organized way to submit, manage, and monitor maintenance requests.
