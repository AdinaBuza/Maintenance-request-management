
Requirements Analysis

Functional Requirements

The application should allow users to:

 Account Access: Create an account and log in.
 Request Submission: Submit maintenance requests with a title, description, category, and priority.
 Tracking: View their submitted requests and check their status.

Technicians should be able to:

 Visibility: View maintenance requests.
 Status Updates: Update request statuses.
 Documentation: Add observations to requests.

Administrators should be able to:

 Management: Manage user accounts and request categories.

Non-Functional Requirements

The application should:

 Usability: Have a simple and easy-to-use interface.
 Security: Protect user accounts and personal data.
 Data Integrity: Store information securely in the database.
 Compatibility: Work correctly in commonly used web browsers.
 Scalability: Be easy to maintain and extend in the future.

Request Statuses

Each maintenance request can have one of the following statuses:

 Submitted
 Pending
 In Progress
 Resolved
